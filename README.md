# Demonstração — Cadastro de empresas em grupos no Jettax

> Projeto de portfólio de **Victória Pedrosa**. **Demonstração** de cadastro de empresas em grupos no Jettax — versão com dados fictícios (nomes, CNPJs, e-mails e IDs internos substituídos).

## Problema de negócio
Cadastrar empresas em grupos no Jettax era repetitivo.

## Antes x depois
| | Antes | Depois |
|---|---|---|
| Como é feito | Cadastro manual no sistema. | Robô lê a planilha e cadastra os grupos. |

## Ganho
- Cadastro em lote.

## Tecnologias
Python, SQLite, Selenium, pandas

## Arquivos
- `cadastrar_grupo.py`
- `requirements.txt`

## Como rodar
1. `pip install -r requirements.txt`
2. Copie `.env.exemplo` para `.env` e preencha os caminhos.
3. Execute o script principal.
